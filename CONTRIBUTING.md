# Contributing

Thank you for helping improve Edge-Case Test Data.

1. Read the README and reproduce the behavior using synthetic data.
2. Open an issue describing the use case before a substantial change.
3. Fork the repository, create a branch, and run `npm ci` followed by `npm test`.
4. Include a regression test for a behavior change and update the affected examples.
5. Submit a focused pull request explaining the problem, change, and validation.

Use Node.js 22 or 24. Browser and container projects document additional checks
in their README. Changes must pass CI on the supported platforms. Never commit
credentials, production logs, or customer records. Contributions are under MIT.
Maintainers review contributions as time permits; no response deadline is promised.
