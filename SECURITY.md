# Reporting security concerns

Report vulnerabilities privately to waleed@ataraxydevelopers.com with the project,
version, impact, and safe reproduction steps. Do not post exploit details or
credentials in public issues. This is the same reporting channel as the
[organization policy](https://github.com/AtaraxyDevelopers/.github/blob/main/SECURITY.md).

Only the latest release is maintained. No response deadline or bounty is promised.
Examples use synthetic data. Read the README's scope and limitations before reuse.
